# AOS — Debian Server with Cockpit

**Серверная сборка на базе Debian 13 amd64 с веб-управлением через Cockpit.**

AOS is an experimental Debian 13-based server ISO for home servers, homelabs and self-hosting. It combines a minimal system without a desktop environment with Cockpit web administration and custom dashboards.

**Статус: Alpha — ранняя тестовая версия.** ISO собран и опубликован. Полная проверка установки и интеграция дополнительных модулей ещё не завершены.

## О проекте

AOS создаётся для домашних серверов и самостоятельного размещения сервисов. Цель — установить минимальную систему без рабочего стола, получить доступ к Cockpit и подключать необходимые функции по мере необходимости.

Основой служит Debian. Проект AOS добавляет собственное оформление Cockpit, страницы управления и конфигурацию установочного образа.

## Основа текущей сборки

В конфигурацию включены:

- **Debian 13 trixie**, архитектура amd64.
- **Cockpit** — управление сервером через браузер.
- Собственное оформление оболочки и бокового меню.
- **AlexServer Monitor** — страница мониторинга.
- **Alex Terminal** — интерфейс управления настроенными процессами.
- **AlexZapretVPN** — страница управления VPN, интеграция которой продолжается.
- Компоненты управления сетью и накопителями.
- Базовые инструменты диагностики сети, дисков и датчиков.
- Текстовый Debian Installer с интерактивным созданием нового пользователя.

Наличие страницы интерфейса не означает готовность всех её функций в новой установке.

## Демонстрация интерфейса

Скриншоты показывают оформление и страницы Cockpit на сервере разработчика. Состав и доступность функций в тестовом ISO могут отличаться.

## Известные ограничения

- Установка на пустой диск и вход в Cockpit после установки ещё не подтверждены испытаниями.
- Автономная установка базы без интернета требует проверки.
- BIOS, UEFI, Secure Boot и Ventoy пока не проверены.
- В текущей тестовой конфигурации nftables отключён; готовая политика брандмауэра отсутствует.
- Адаптация VPN, правил маршрутизации и watchdog продолжается.
- Управление вентиляторами отключено по умолчанию и требует проверки совместимости оборудования.
- Побитовая воспроизводимость ISO пока не обеспечена.

Для первого знакомства рекомендуется отдельная виртуальная машина.
